Tic Tac Toe AI

A browser-based Tic-Tac-Toe game with three levels of AI difficulty.

Project Overview

This project is a browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

The main goal of the project was to build a Tic-Tac-Toe AI with multiple difficulty levels and gradually improve the bot's decision-making. Instead of using an external AI service or library, the AI logic was implemented manually in JavaScript.

The game currently has three difficulty levels: Easy, Medium, and Hard.

How to Play

The player plays as X, while the AI plays as O.

The player selects an empty cell to place X. The AI then makes its move. The game continues until either the player or AI gets three matching symbols in a row, column, or diagonal, or until all cells are filled and the game ends in a draw.

The game also includes a restart option and messages for different game situations.

Difficulty Levels

01

Easy

The Easy level uses simple decision-making. The AI chooses an available move without trying to predict the player's future moves.

This makes the AI relatively easy to beat and is intended as an introductory difficulty.

02

Medium

The Medium AI uses a rule-based strategy.

It first checks whether it can win immediately. If it cannot win, it checks whether the player has an immediate winning opportunity and blocks it.

After that, it prioritizes the center, followed by available corners. If none of those options are available, it chooses from the remaining moves.

This makes the Medium AI more strategic than the Easy AI without requiring a full game-tree search.

03

Hard

The Hard level uses the Minimax algorithm to evaluate possible future game states.

The AI simulates its own moves and the player's possible responses, allowing it to make decisions based on future outcomes rather than only the current board.

AI Win +1
Draw 0
Player Win -1

The AI tries to maximize its score while the simulated player tries to minimize it.

04

Impossible

The Impossible level is designed to play Tic-Tac-Toe optimally using the Minimax algorithm.

Instead of choosing a move based only on the current situation, the AI explores every possible continuation of the game and evaluates the resulting outcomes.

The AI always chooses the move with the best guaranteed outcome. If the player also plays perfectly, the game will end in a draw. The player cannot force a win against an optimal Tic-Tac-Toe AI.

AI Win +1
Draw 0
Player Win -1

This is the highest difficulty and is intended to be effectively unbeatable.
